# 片头视频自动恢复播放

用途：供 Agent 实现片头视频自动恢复播放。

## 播放恢复逻辑

1. **自动播放失败**：`video.play()` 被拒绝后，设置 `video.muted = true`，再次尝试播放。
2. **意外暂停**：监听 `pause`。片头已结束、视频已播完、SDK 主动暂停或页面隐藏时不恢复；其他情况尝试静音续播。用户操作过声音按钮时，先按当前声音状态续播，失败仍回退静音。
3. **定时检查**：每 **500ms** 检查一次。已开始且页面可见、未被主动暂停时，若 `video.paused` 则尝试静音续播；若正在静音播放，则尝试开启声音，并在 **120ms** 后检查，若因此暂停则恢复静音播放。用户操作声音按钮后停止定时检查，但保留 `pause` 监听。
4. **返回前台**：SDK 通知可见，或页面重新可见且视频尚未结束时，尝试续播。
5. **超时兜底**：设置 **30 秒**超时结束片头；后台或 SDK 暂停时冻结计时。如果有等待用户点击 GO 的状态，进入该状态后取消超时。

## 限制与实现要求

- 本方案主要检查 `video.paused`，**没有持续检测 `currentTime` 是否前进**；画面卡住但 `paused === false` 时，不一定能发现。
- 恢复播放只是尝试，浏览器仍可能拒绝；在调用 `play()` 前记录的恢复尝试日志，不能作为恢复成功的证据。
- 实现时区分主动暂停和意外暂停，保留用户声音选择；所有异步重试都应检查页面可见、生命周期和结束状态，并在销毁时清理定时器、延迟回调和监听器。
- 验证：自动播放被拒绝、意外暂停、切后台再返回、声音按钮操作、视频结束后不被重启。实现后需进行真机验证。
