# Colorever New 图案设计规范

制作适合手机试玩、独立看也有美感的珠子图案：轮廓清楚、比例协调，并保留配色、材质和细节层次。先设计好完成图，再调整开局和操作体验。实际模板中的显示效果是验收依据，数值达标不能替代美感。

## 适用范围

默认只制作和优化 `colorever-new`，包括目标图案及必要的注册、构建产物和验证。不将图案或代码同步到 `colorever-abandoned`、其他模板或仓库。用户明确指定的范围和本次要求优先。

图案制作沿用现有珠子材质、反光、凹槽、缓存栏和游戏规则。图案的主要结构由可玩的珠子组成；新图案默认不增加额外装饰模型。已有图案的专属装饰需要结合本次需求判断，不批量移除。

## 设计标准

| 方面 | 设计方向 |
| --- | --- |
| 网格与密度 | 按造型选择网格：简单主体可尝试 24～32 格，复杂珠宝、人像可用 32～40 格。所有珠子同尺寸、等间距，不为减少搬运强制降低分辨率。 |
| 主体与比例 | 每张图突出一个主要对象，保留完整轮廓和最有辨识度的特征。允许适度放大眼睛、耳朵、十字、门窗等关键部位。 |
| 细节取舍 | 合并无意义噪点，保留影响美感的纹样、镶边、反光和关键结构。戒指的金托、镶爪、内外壁及宝石切面是造型内容，不能当作杂点一起删掉。 |
| 色块组织 | 主要区域连续，明暗顺着结构分布；允许五官、切面边缘等必要小色块，不把物件压成几块平涂色面来追求搬运量。 |
| 配色 | 可从 6～8 色起步，根据造型增加明暗与材质色。每种颜色有用途，主色协调，重要区域有对比；不追求尽可能少色，也不默认压缩到 4 色。 |
| 背景与留白 | 主体占据主要画面，四周留出适当空间。只有承担构图作用的底色、边框才使用珠子，不为填满矩形增加无意义背景珠子。 |
| 风格统一 | 描边粗细、细节密度和明暗方向一致；先让缩小的平面图清楚、好看，再用模板渲染增加珠子质感。 |

网格和色数是表现手段。优化已有图案时对照修改前的实际渲染，确认比例、配色、层次和整体美感没有明显退步。图案可以不像原图，但必须独立好看；不能只证明它“看得懂、步数少”。

## 从参考图到可辨识图案

参考图用于确定核心题材。制作后先在手机缩略图中判断“能否第一眼认出是什么”，再决定细节是否值得保留。看不清时，先改轮廓、比例和构图；允许舍弃原姿态、放大局部，或重画同题材主体。不要只靠反复换配色修补无法辨认的造型。

| 常见问题 | 调整方向 |
| --- | --- |
| 丝巾像普通色块 | 保留布料折叠、垂落、打结或飘带等轮廓线索；花纹服从大形。 |
| 木马、金属鸟等复杂外形认不出 | 先表达“马”或“鸟”。马可放大头部，突出长口鼻、耳朵和鬃毛；鸟保留清楚的头、眼、喙、翅和尾，舍弃零碎机械饰件。 |
| 黄色小鸟头部模糊 | 可重新设计为可爱的小黄鸟，用清楚的眼睛、喙、身体和翅膀建立辨识度，不必照搬参考姿态。 |
| 金属饰物和黑色盒子颜色沉闷 | 可重新选用明亮协调的主色、清楚的明暗和少量强调色；盒盖以大而清楚的 BOX 等短字代替复杂徽章，不保留难拼的小花纹。 |
| 人像太小、五官不清 | 改为脸部特写；用户指定已有优秀图案时参考其脸部比例与构图，再保留本图发色等特征。 |
| 红唇、猫耳、柱子、裙子缺乏完整构图 | 根据要求加入衬托主体的背景框，拉开主体与底色的对比；耳朵保持清楚的外形和内耳，复杂龙纹柱可简化为好看的柱子。 |

背景框有衬托、分隔和收束构图的作用。保留有用的底色、层次和边框，不为降低搬运量破坏已成立的构图；只删除无意义的填充和重复噪点。

## 全局大块归位的操作预算

每张新增或修改的图案都用编辑器当前的“适中 · 全局大块归位”验收。先保证完成图的美感，再测 95% 错位；若无法求解或超过 80 次，**保留同一完成图，优先改为 80% 错位复验**，而不是删掉材质、切面、细节或降低网格。80% 下完整解法不超过 80 次即符合要求，无需强求 95%。单批上限保持 30，使用图案种子和缓存配置；实际任务也要同参数复验。

一次入篮或归位记一次搬运，拾取不计步；平均搬运量不包含缓存自动整理位移。平均搬运数及大小批占比只作为诊断，不设至少 12 颗等统一门槛。必要的小批搬运可以保留，不能为了均值把金属明暗、宝石切面或五官抹平。

80% 仍超标时，优化不影响美感的碎色、冗余与开局预算；保留有美感的版本并如实报告冲突，不将粗糙版本标记为升级成功。不要挑有利种子、随意增大单批或缓存、改引擎来掩盖问题。自动回放使用当前实际入口，不能以旧版适中 12～14 步代替。

交付明确记录最终采用 80% 还是 95%，预览链接和广告任务与该设置一致。校验器会报告尝试过程和推荐配置，但不修改编辑器或引擎的默认值。珠子总量除以批量上限只能粗估，实际步数以回放为准。

## 图案与渲染的职责

图案数据负责主体的形状、配色、结构性明暗和材质表达，例如金属内外壁、宝石切面、衣褶和物件高光。模板渲染负责每颗珠子的表面光泽和立体感，不能指望它替缺失的物件结构补出质感；也不逐颗堆色模拟珠子自身的高光。珠子保持本色，底部目标色容器保持完整、不透明。

改变网格或配色时，检查缓存容量与连续色块是否仍支持现有开局模式。开局应能辨认主体，并保留最重要的结构；默认种子是演示选择，不是所有广告任务固定使用的开局。

## 实际模板验收

在 320px 和 390px 宽的手机视口中，查看完成图、开局和珠子移走后的空槽，并实际完成一轮操作。截图应来自模板渲染。

- 完成图是否好看，比例、配色和材质层次是否成立；与修改前相比是否有美感退步？
- 第一眼能否认出主体，关键特征是否保留？
- 各颜色是否形成清楚、有意义的区域，缩小后有无碎色或生硬分块？
- 删除非关键细节后，画面是否更清楚；主体、边框和留白比例是否合适？
- 开局是否仍能辨认主体，珠子与目标色槽位是否清楚、可点中？
- 数据校验、选定 80% 或 95% 错位下的全局模式 ≤80 次搬运和实际操作是否通过，交付参数是否一致？

自动校验只说明数据和求解结果符合要求，不能代替视觉判断。完成图截图也不能代替开局和触摸检查。

## 每次任务需要提供的信息

提供参考图、图案名称或已有 ID，以及需要突出或保留的部位。指定的网格、配色、替换范围和交付形式优先于默认建议。没有特别要求时，按上面的设计标准处理。
