# Colorever New 图案设计规范

制作适合手机试玩的珠子图案：用较少、较大的珠子表达轮廓清楚、配色协调、色块完整的主体。先设计好完成图，再检查开局和操作体验。实际模板中的显示效果是验收依据。

## 适用范围

默认只制作和优化 `colorever-new`，包括目标图案及必要的注册、构建产物和验证。不将图案或代码同步到 `colorever-abandoned`、其他模板或仓库。用户明确指定的范围和本次要求优先。

图案制作沿用现有珠子材质、反光、凹槽、缓存栏和游戏规则。图案的主要结构由可玩的珠子组成；新图案默认不增加额外装饰模型。已有图案的专属装饰需要结合本次需求判断，不批量移除。

## 设计标准

| 方面 | 设计方向 |
| --- | --- |
| 网格与密度 | 简单主体优先尝试约 24～32 格的粗网格。所有珠子同尺寸、等间距；根据形状调整宽高，必要时可增至当前引擎支持的 40×40。 |
| 主体与比例 | 每张图突出一个主要对象，保留完整轮廓和最有辨识度的特征。允许适度放大眼睛、耳朵、十字、门窗等关键部位。 |
| 细节取舍 | 在粗网格中重新设计参考图，合并纹理、花纹、镶边和细碎反光。关键结构用数颗珠子表达，避免依赖大量单格点缀。 |
| 色块组织 | 同色区域连续并具有造型；明暗顺着结构分布，减少无缘由的补丁、相近颜色交错和孤立色点。 |
| 配色 | 优先约 6～8 色，每种颜色有明确用途。主色鲜明协调，相邻重要区域有足够的色相或明度差；按题材调整，不机械限制数量。 |
| 背景与留白 | 主体占据主要画面，四周留出适当空间。只有承担构图作用的底色、边框才使用珠子，不为填满矩形增加无意义背景珠子。 |
| 风格统一 | 描边粗细、细节密度和明暗方向一致；先让缩小的平面图清楚、好看，再用模板渲染增加珠子质感。 |

24～32 格、6～8 色是起点，不是硬性上限。复杂度增加应服务于主体辨识度；如果只是增加纹理噪点，应先简化。

## 从参考图到可辨识图案

参考图用于确定核心题材。制作后先在手机缩略图中判断“能否第一眼认出是什么”，再决定细节是否值得保留。看不清时，先改轮廓、比例和构图；允许舍弃原姿态、放大局部，或重画同题材主体。不要只靠反复换配色修补无法辨认的造型。

| 常见问题 | 调整方向 |
| --- | --- |
| 丝巾像普通色块 | 保留布料折叠、垂落、打结或飘带等轮廓线索；花纹服从大形。 |
| 木马、金属鸟等复杂外形认不出 | 先表达“马”或“鸟”。马可放大头部，突出长口鼻、耳朵和鬃毛；鸟保留清楚的头、眼、喙、翅和尾，舍弃零碎机械饰件。 |
| 黄色小鸟头部模糊 | 可重新设计为可爱的小黄鸟，用清楚的眼睛、喙、身体和翅膀建立辨识度，不必照搬参考姿态。 |
| 金属饰物和黑色盒子颜色沉闷 | 可重新选用明亮协调的主色、清楚的明暗和少量强调色；盒盖以大而清楚的 BOX 等短字代替复杂徽章，不保留难拼的小花纹。 |
| 人像太小、五官不清 | 改为脸部特写；用户指定已有优秀图案时参考其脸部比例与构图，再保留本图发色等特征。 |
| 红唇、猫耳、柱子、裙子缺乏完整构图 | 根据要求加入衬托主体的背景框，拉开主体与底色的对比；耳朵保持清楚的外形和内耳，复杂龙纹柱可简化为好看的柱子。 |

背景框有衬托、分隔和收束构图的作用，但也增加可玩珠子与搬运负担。优先简洁、连续的框和底色，避免多层碎边与无意义的满幅填充。珠子总量、框的面积和主体大小需一起考虑。

## 全局大块归位的操作预算

每张新增或修改的图案都用编辑器当前的“适中 · 全局大块归位”验收，完整解法 **不超过 50 次成功搬运**。默认错位目标 95%、单批最多 30 颗，使用源图案种子及缓存配置；实际广告参数也要复验。必须调用当前入口回放，不能拿旧版适中模式的 12～14 步结果代替。命令和参数见 skill。

一次入篮或归位记一次搬运，拾取不计步；平均每次搬运的珠子数不包含缓存自动整理位移。默认单批 30 时，以平均至少 12 颗为优化参考，条件允许向 20～30 颗靠拢，同时降低 1～2 颗的小批占比。均值高也不能抵消总步数超标；小图不为凑均值增加无用珠子。

造型阶段就组织好大块连续同色区域：合并邻近色与细碎高光，简化纹理、描边、饰件和背景，让主色区足够宽、连贯，减少孤立点和细长断线。保留眼睛、嘴等必要的小色块，不为搬运指标牺牲主体辨识度。珠子质感交给渲染表达。

超过 50 次时，优先缩减非关键细节与背景、合并碎色、减少珠子总量，必要时改为局部特写或缩小网格；重新检查视觉和实际回放。不要为了达标降低错位比例、增大单批或缓存、挑选有利种子或改引擎。用户明确要求不同配置时记录差异，并在该配置下验收。珠子总数除以批量上限只能粗估，实际还有入篮、碎块和往返搬运，最终以回放为准。

## 图案与渲染的职责

图案数据负责形状、色块与配色。珠子的亮面、圆角反光、切面明暗和立体感由模板统一渲染，不通过堆叠相近颜色模拟每颗珠子的高光。珠子保持本色，底部目标色容器保持完整、不透明。

改变网格或配色时，检查缓存容量与连续色块是否仍支持现有开局模式。开局应能辨认主体，并保留最重要的结构；默认种子是演示选择，不是所有广告任务固定使用的开局。

## 实际模板验收

在 320px 和 390px 宽的手机视口中，查看完成图、开局和珠子移走后的空槽，并实际完成一轮操作。截图应来自模板渲染。

- 第一眼能否认出主体，关键特征是否保留？
- 各颜色是否形成清楚、有意义的区域，缩小后有无碎色或生硬分块？
- 删除非关键细节后，画面是否更清楚；主体、边框和留白比例是否合适？
- 开局是否仍能辨认主体，珠子与目标色槽位是否清楚、可点中？
- 数据校验、当前全局模式 ≤50 次搬运和实际操作是否通过，平均搬运数与小批占比是否仍有明显优化空间？

自动校验只说明数据和求解结果符合要求，不能代替视觉判断。完成图截图也不能代替开局和触摸检查。

## 每次任务需要提供的信息

提供参考图、图案名称或已有 ID，以及需要突出或保留的部位。指定的网格、配色、替换范围和交付形式优先于默认建议。没有特别要求时，按上面的设计标准处理。

日常操作、最小读取范围和现成命令见 [colorever-patterns skill](../.agents/skills/colorever-patterns/SKILL.md)。
