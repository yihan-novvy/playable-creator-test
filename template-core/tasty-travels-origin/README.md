# Tasty Travels Origin

Cocos Creator 2.4.10 原版投放饮品、碰撞合成试玩。冻结 HTML、素材指纹、商店 ID、发行方和 SHA-256 见 `source/provenance.json`；未独立确认素材作者。

构建读取原 HTML 的内嵌 ZIP 与资源字典，保留引擎、物理碰撞、原关卡、音效与资源加载器。原核心仅在模块加载末尾添加独立适配器入口；广告平台启动与下载替换为项目桥。ZIP 只解析至内存，不按归档路径写磁盘，无新增依赖。

可选剧情开场的三张用户参考截图保存在 `source/story/`，构建原样复制至模板，插件仅在启用 `story.enabled` 时将其内嵌。剧情 DOM 与固定对白由插件维护；boot 将 `novvy:story-finished` 作为游戏进入信号，视频结束不提前恢复游戏。

加载页内嵌原 HTML 中的 Tasty Travels Logo，恢复条纹动画与原生资源进度条；Loading 文案独立于进度填充。启动先给浏览器绘制页面的机会，再初始化引擎，场景首帧绘制完成后收起加载页。纯试玩直接显示加载页；有片头时在视频后面加载场景，首帧准备好后暂停玩法并保持静音，片头退出（包括等待 GO 点击）后才恢复。已就绪时直接进入游戏，尚未就绪时保留 Loading 兜底；加载页层级低于片头、高于 HUD 和 CTA。无需外链素材或人为延长加载时间。

画布铺满当前页面或 iframe，不请求浏览器自动全屏。构建时关闭原版异步启动回调中的自动全屏，防止其覆盖外层 boot 的关闭设置；已有导出包需重新打包。双摄像机在场景内给顶部 HUD 和底部 CTA 卡留白，背景边缘使用原素材延展。物理节点不变，触摸坐标经摄像机逆变换后交回原玩法。移除游戏声音开关及横竖屏原下载按钮，音乐默认开启；浏览器限制自动播放时由首次触摸解锁。CTA 使用共享卡片，显示名称为 Tasty Travels，图标取自 App Store 并离线随包内嵌，预览和打包一致；商店原名、来源、获取日期和图标哈希记录在 `source/app-store.json`。

竖屏原生金币栏和下一杯提示位于顶部两侧，HUD 第一行文字的顶部对齐 NEXT 文字的底部，顶部间距随屏幕高度在 64–92px 之间调整。玩法固定使用原包英文文案及 `order1-en` / `order2-en` 订单素材，不跟随浏览器语言。

开局引导的指尖锚定中央待投放酒杯，配合金色呼吸光圈、白色箭身金色细边的双向箭头和两侧半透明酒杯提示左右拖动。箭头从酒杯后方连续穿过，以杯身和瞄准线的共同中轴对齐，消除原生精灵透明留白偏移造成的左右露出长度差；宽度约占竖屏画面的三分之一，带柔光和轻微呼吸动画；运行时生成高清纹理，场景销毁时释放。沿用原版手指与当前饮品素材，提示节点独立于物理物品列表；随横竖屏布局更新位置，首次操作后收起，并停用原版投放后的重复幽灵提示。预览和重新打包均使用此效果；模板重建后需重启已运行的编辑器服务以刷新构建清单缓存。

`npm run build -w template-core/tasty-travels-origin`；`npm test -w template-core/tasty-travels-origin`。测试覆盖原生同类碰撞规则、最高级限制、碰撞去重、源哈希与确定性构建，以及桌面/移动端的首帧就绪、片头预加载、静音暂停、提前结束片头与可见性恢复；各路径均不重新启用自动全屏。
