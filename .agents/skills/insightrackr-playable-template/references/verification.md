# 验收与交付

## 静态与自动检查

以实际模板 ID 替换示例变量；命令由当前仓库提供，不存在时按现有测试结构补必要测试。

```sh
npm run build -w "template-core/$TEMPLATE_ID"
npm test -w "template-core/$TEMPLATE_ID"
node editor/test/run-all.mjs "$TEMPLATE_ID"
npm run validate
```

至少覆盖真正有风险的行为：源完整性/补丁锚点、确定性构建、可核实的玩法约束、空点击/无效移动不记步、有效操作与进度分离、异步回调去重、换关、最终胜负、CTA 来源/节奏，以及视频启用和关闭时的前置条件。测试不是对字段名和注释的逐字复述。

修改共享 runner、配置存储或桥时运行相应回归。全仓失败要定位到具体套件；怀疑基线问题可用隔离的未修改 HEAD 副本复现，不能重置用户工作区。只说实际复现过的基线失败。长时间无进展的旧套件应调查并记录未完成状态，不能无限等待或宣称全绿。

## 真实浏览器验证

复用归属已确认的目标项目 editor；端口占用先核对服务，不关闭别人的进程。文件更新后 reload，不能沿用旧包截图。浏览器工具按其文档操作；为查看事件可在本地 QA 壳注入模拟 SDK 并输出日志，不在页面偷偷修改游戏状态来冒充真实试玩。

检验适用场景：

- 手机竖屏和横屏：实际拖动/点击、正确和错误操作、画布适配、按钮可达、标题不叠字、静音开关。
- 纯 playable 开局，视频自然结束进入试玩，可选 GO 模式；播放前段声明与媒体注册正确，切段一次，视频期间游戏未提前运行。
- 初次移动、成功消除、教学到后续关卡：step 和 progress 与实际变化一致，不把“没进度”误判为“无有效操作”。
- 策略触发、主动 CTA、回访后继续玩：来源正确、无原生裸跳、无双击链路、无永久锁输入。
- 最后一步、真实失败、未完成离开、可重玩分支：各自的结算语义和去重正确。不能只调用模拟 manager 就宣称真实引擎已经完整过关。
- 浏览器控制台错误和资源依赖。可以在独立 QA 壳限制外部连接或记录资源请求来发现隐含 CDN；不要把阻止 SDK 注入的限制写入生产包。

## 重玩与 HUD 专项

接入 [重玩与 HUD 标题](replay-and-hud.md) 时覆盖以下行为。

- 分别检查重玩关闭、开启和旧任务缺配置。真实成功/失败各结算一次；关闭时原生重玩入口不可绕过开关，开启时保留当前阶段。连续完成多轮成功/失败重开，核对 CTA 先于重置、每次一次、场景就绪才报 `onReplay`；连点被拦截，加载失败可以重试。
- 每轮恢复初始棋盘/资源、引导、计时及本局 step/progress/CTA 首跳阈值；片头和 stage 不重复，音乐实例、订阅、定时器和动画不累积。重玩后实际移动、投放或合成仍有效，不止看新画面出现。
- HUD 标题开/关、仅主标题/仅副标题、空文案与长文案在竖屏和横屏都可用；确认完整画布、上下安全区、原生计数/提示与 CTA 不遮挡、标题不拦输入。旋转、GO 切段、换关和重玩后检查布局与拖拽命中，不能只做 DOM 字符串检查。
- 在工作台分别修改两行标题及重玩开关，刷新并读回；同级配置保留，旧 pack 失效且旧 ZIP 不可导出，已有转码保留，重新 pack 后预览/成品一致。官方图标与名称随包，声音/可见性行为仍正确。
- 可用显式本地 QA 入口触发难以手动达到的最终成功、失败或加载异常；这些只能证明相应运行时分支。报告清楚是自然玩法到达还是 QA 触发，测试入口和 SDK 桩不得进入导出物。

模板自身套件之外，配置保存/打包变化参考 `origin-editor`，HUD/CTA 一致性参考 `origin-consistency`，共享转化分支参考 `cta-continuation`；只运行本次改动相关的套件，不能用已有套件的通过替代新模板的真实引擎验证。

## 打包验证

- 在工作台改配置并读回，确认重跑和过期状态；运行真实 pack 和导出入口。
- 解开 ZIP 检查唯一根 `index.html`、相对资源引用、无测试桩/QA HTML/临时报告；仅打包必要的转码媒体及资产。
- 打包后直接从成品路径试玩，按仓库广告基线检查 `file://` 运行。若工具不能验证本地文件，明确该项未验证，不能把 localhost 成功当成 file 成功。
- 重复 pack 比较文件清单和内容；开启视频后再关闭视频，确认旧视频文件不残留。
- 项目 source 和生成模板需要一并交付；不要把 project/result 里的测试任务加入 Git。保留用户可复查的示例任务及实际产物，清掉本次临时 QA 数据。
