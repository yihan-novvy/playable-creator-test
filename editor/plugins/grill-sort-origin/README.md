# Grill Sort Origin 插件

模板 ID `grill-sort-origin`。支持片头 MP4、GO、顶部标题和 CTA，默认纯试玩；片头使用 core:intro 转码结果。

有效手动放置记步，自动补货、同位放回和空点不记步。进度是已完成打包数量 / 120；原生打包动画完成后立即补报当前步的进度，最终 100% 在 win 之前上报。120 串完成发送 win，原生 180 秒耗尽发送 fail。原版结果页的 Try Again 实际是商店入口，无同段重玩，不伪造 onReplay。

默认第 20 步首跳，之后间隔 10/8/6/4，末间隔循环。原生 CTA 转统一 click；跳店不结算。背景暂停游戏和倒计时。视频结束后才启动原版引擎。

自动化覆盖有效放置、真实进度、失败/胜利去重、视频门控、静音和原生 CTA。浏览器实测拖拽三消、2.5% 打包进度、180 秒自然失败、结果页 CTA、视频 GO 切段与横屏标题。生产 SDK、真机 WebView 和完整 120 串通关未实测。

三套共同验收与限制见 `docs/three-origin-templates-verification.md`；已测试 390×844 手机视口内真实操作、横屏和视频 GO 链路。

转化统一复用 core CTA bridge：步数循环已触发后，通关不重复自动跳转；最终通关后普通触压可再次转化，Canvas 下载按钮保留 `cta_click` 且不重复。无 SDK 的编辑器预览只记录触发，不调用原版跳转兜底。
