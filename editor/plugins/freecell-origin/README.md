# FreeCell Origin 插件

模板 ID：`freecell-origin`。可选择片头 MP4、GO、顶部两行标题和 CTA 节奏；默认纯试玩。片头启用时复用 `core:intro`，仅打包转码视频与 poster。

合法牌列/暂存格/收牌区移动产生一次 `onStep`，进度为实际收牌数 / 52。空点不记步；自动收牌不虚增手势，收齐时在最后一次有效操作上补报 100% 进度，再发送 win。原版检测无可用移动时发送 fail。CTA 使用统一 click API，普通背景/失焦不结算。

`gameplay.allowReplay` 默认关闭，旧任务未配置时也关闭。工作台「游戏设置 → 允许重玩」开启后，通关或无可用移动时显示英文结算与重玩按钮，结果使用 `continue_playing: true`。点击先通过统一 `novvy:replay-cta` 触发下载卡跳转，再重新发牌并上报同段 `onReplay`；计步、进度和首跳阈值重置，片头与阶段不重复。清理旧牌局的计时器、动画、粒子和事件订阅，复用背景音乐。关闭时隐藏原生失败重玩按钮，保留原生通关展示，结果结束阶段。设置变更只需重新打包。

默认第 20 次有效操作首跳，后续间隔 10、8、6、4（末间隔循环），可改为完成时跳转。所有原生 CTA 归为主动点击，回店后继续玩法。

验证：源规则、适配器/打包、配置接口和共享 CTA 检查通过；浏览器实测纸牌移动、暂存格、收牌进度、手机和横屏布局、视频 GO 切段、CTA 后继续移动，以及通过本地通关/无可用移动测试入口触发的连续重玩。重玩后恢复 52 张唯一纸牌、可正常移牌、音乐与事件监听不累积。生产 SDK/广告 WebView 与完整 52 张牌手动通关未实测；本地 QA SDK 只用于验收，不能进入导出物。

三套共同验收与限制见 `docs/three-origin-templates-verification.md`；已测试 390×844 手机视口内真实操作、横屏和视频 GO 链路。

转化统一复用 core CTA bridge：步数循环已触发后，通关不重复自动跳转；关闭重玩时最终通关后普通触压可再次转化，开启时不武装逐次触压跳转，重玩按钮每次只触发一次 CTA。Canvas 下载按钮保留 `cta_click` 且不重复。无 SDK 的编辑器预览只记录触发，不调用原版跳转兜底。
