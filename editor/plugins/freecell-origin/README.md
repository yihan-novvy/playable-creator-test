# FreeCell Origin 插件

模板 ID：`freecell-origin`。可选择片头 MP4、GO、顶部两行标题和 CTA 节奏；默认纯试玩。片头启用时复用 `core:intro`，仅打包转码视频与 poster。

合法牌列/暂存格/收牌区移动产生一次 `onStep`，进度为实际收牌数 / 52。空点不记步；自动收牌不虚增手势。原版检测无可用移动时发送 fail 并允许同段 `onReplay`，最终收齐牌发送 win。CTA 使用统一 click API，普通背景/失焦不结算。

默认第 20 次有效操作首跳，后续间隔 10、8、6、4（末间隔循环），可改为完成时跳转。所有原生 CTA 归为主动点击，回店后继续玩法。

验证：源规则测试与 33 项适配器/打包检查通过；浏览器实测纸牌移动、暂存格、收牌进度、手机和横屏布局、视频 GO 切段、CTA 后继续移动。生产 SDK/广告 WebView 与完整 52 张牌通关未实测；本地 QA SDK 只用于验收，不能进入导出物。

三套共同验收与限制见 `docs/three-origin-templates-verification.md`；已测试 390×844 手机视口内真实操作、横屏和视频 GO 链路。

转化统一复用 core CTA bridge：步数循环已触发后，通关不重复自动跳转；最终通关后普通触压可再次转化，Canvas 下载按钮保留 `cta_click` 且不重复。无 SDK 的编辑器预览只记录触发，不调用原版跳转兜底。
