# Tasty Travels Origin 插件

模板 ID `tasty-travels-origin`。原版是投放饮品与碰撞合成试玩；支持片头、GO、两行标题、CTA 节奏。默认纯试玩，第 20 次有效操作首跳，之后间隔 10/8/6/4，末间隔循环。

一次被引擎接受并消耗待投放物的操作记一步；空抬手、点击下载、单次投放产生的多次连锁合成不重复记步。进度为事件发生时已合成最高等级 / 9，属于等级进度，不是剩余操作数估算。最高级触发原版 EndStep 为 win，原生越界 EndStep 为 fail；不从 CHALLENGE_SOLVED 等误标的原生触摸统计推断结果。无原生重玩，不伪造 replay。

原生下载触摸停止传播，抬手不会误投放；CTA 不结束段。结果后普通背景不转商店。视频结束才启动物理引擎，后台暂停物理与声音。

浏览器实测有效投放、碰撞合成、11.11%/22.22% 进度、原生 CTA 与后续继续操作；自动化验证结果分流、去重、视频门控及配置。生产 SDK、真机 WebView、完整最高级通关未实测。

三套共同验收与限制见 `docs/three-origin-templates-verification.md`；已测试 390×844 手机视口内真实操作、横屏和视频 GO 链路。
